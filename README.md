# STRIKER ROGUE: Street to Stadium

A Game Boy Color / GBA-style roguelite football RPG built with HTML5 Canvas. Explore procedural towns, street cage dungeons, and championship stadiums, recruit a 5-a-side squad, and battle in 3-phase turn-based football matches!

## Controls
- **Move / Navigate:** `Arrow Keys` or `WASD` (or use the on-screen D-Pad / tap tiles on mobile)
- **Confirm / Act (`A`):** `Z`, `Enter`, `Space` (or keys `1`–`4` in matches)
- **Back / Cancel (`B`):** `X` or `Esc`
- **Squad & Bag Menu (`START`):** `M`
- **Quest & Tactical Guide (`SELECT`):** `Q`

## Play Online
Open `index.html` in any browser, or play via GitHub Pages once enabled in repository settings.
